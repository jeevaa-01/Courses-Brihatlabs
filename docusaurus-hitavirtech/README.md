# PySpark for Data Engineering — HitaVir Tech Course Site

A Docusaurus **3.10** course website for the HitaVir Tech *PySpark for Data Engineering* program
(Batch 6). Six modules, 25 sections, interactive knowledge checks, a peer-reviewed capstone,
and a graded final quiz — running end to end on **Databricks Free Edition**.

## Quick start

```bash
npm install
npm run start     # dev server at http://localhost:3000
npm run build     # static site in ./build
npm run serve     # preview the production build
```

Requires Node.js >= 20.

## Docusaurus 3.10 capabilities used

- `future.v4: true` — opts in to Docusaurus v4 behavior ahead of the major release
- `future.faster: true` — Docusaurus Faster build pipeline (Rspack + SWC)
- **Interactive quizzes** — custom `<Quiz />` React component (`src/components/Quiz`),
  registered globally via `src/theme/MDXComponents.js`; every section's knowledge check is
  a self-grading quiz with per-question feedback
- **Synced environment tabs** — `<Tabs groupId="env">` for Databricks vs. local Windows code;
  the learner's choice persists across all pages
- **Admonitions** — tips, pro tips, ANSI-mode warnings, null-logic dangers, key takeaways,
  learning objectives, and discussion prompts
- **Mermaid diagrams** (`@docusaurus/theme-mermaid`) — Spark architecture and medallion flows
- **Collapsible `<details>`** — exercise solutions and the final-quiz answer key
- **Autogenerated sidebar** with per-module `_category_.json` and generated category index pages
- **Custom landing page** (`src/pages/index.js`) with module cards, HitaVir Tech navy palette,
  Space Grotesk / Inter typography (`src/css/custom.css`)
- Blog (course announcements), dark mode default, announcement bar, sitemap, social card

## Access gate (HitaVirTech Codelabs style)

The site ships with the same Cloudflare Pages Functions gate used by
[codelabs.hitavirtech.com](https://codelabs.hitavirtech.com): every request runs through
`functions/_middleware.js`, which requires a signed `hv_session` cookie issued after
**Google sign-in** (`/auth/login` → Google → `/auth/callback`) and re-checks the student
allowlist on every page load.

- **`functions/_allowlist.js`** — the ONLY file you edit to control access.
  Seeded with the B4 + B5-April-2026 cohorts from the codelabs allowlist; keep the two in sync.
- `/auth/whoami` — returns the caller's `{ email, access }` for client scripts.
- `/auth/logout` — clears the session.
- `RESTRICTED_PATHS` is empty by default (whole course open to all enrolled students);
  add path prefixes there to gate specific modules to specific batches.

### Required secrets (all managed as GitHub repo secrets)

Everything is configured from GitHub → Settings → Secrets and variables → Actions.
The deploy workflow syncs the gate secrets into the Cloudflare Pages project on every
deploy (`wrangler pages secret put`), so the Cloudflare dashboard never needs editing.

| Secret | Purpose |
|---|---|
| `CLOUDFLARE_API_TOKEN` | API token with *Cloudflare Pages — Edit* permission |
| `CLOUDFLARE_ACCOUNT_ID` | Cloudflare account id (shown in every dashboard URL) |
| `GOOGLE_CLIENT_ID` | Google OAuth web client (redirect URI `https://learn.hitavirtech.com/auth/callback`) |
| `GOOGLE_CLIENT_SECRET` | Its secret |
| `SESSION_SECRET` | Random 32+ byte string for HMAC-signing session cookies (`openssl rand -hex 32`) |

For local testing with `wrangler pages dev`, copy `.dev.vars.example` to `.dev.vars`.

## Deployment

**Repo:** [hitavir25/docusaurus-hitavirtech](https://github.com/hitavir25/docusaurus-hitavirtech) ·
**Domain:** `learn.hitavirtech.com` (custom domain on the Cloudflare Pages project `hitavirtech-docusaurus`).

Pushes to `main` trigger `.github/workflows/deploy.yml`: `npm ci` → `npm run build` →
secret sync → `wrangler pages deploy build` (which bundles `functions/` — the access
gate — automatically). Security headers live in `static/_headers`.
