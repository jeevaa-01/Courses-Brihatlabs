<KeyTakeaways>

- Three patterns — data lake, data warehouse, Lake House — cover 95% of production analytics
- Lakes store anything cheaply; warehouses serve fast SQL on curated tables
- The Lake House (Modern Data Architecture) combines the best of both
- The rest of this course tours each pattern, then the six real-world shapes built from them
