# Fundamentals of Analytics on AWS — Part 2

**Instructor:** HitaVir Tech · **Level:** Beginner · **Estimated total:** ~85 minutes · **4 modules · 12 lessons**

Welcome to **Fundamentals of Analytics on AWS — Part 2** by **HitaVir Tech**!
This is **Part 2 of 2**. In Part 1 you built the mental model — analytics
concepts, the 5 Vs, and the AWS services that solve each V. In Part 2 you zoom
out and learn **how those services combine** into production architectures used
by real companies today.

![AWS](/img/courses/aws-icons/aws.png)

<LearningObjectives>

- Explain what data lakes and data warehouses are, and when to use each
- Describe the five pillars of Modern Data Architecture (the Lake House pattern)
- Map every major AWS analytics service to its layer in the architecture
- Recognize the six reference architectures that power 95% of real-world analytics

</LearningObjectives>

## Prerequisites

- Completing **Fundamentals of Analytics on AWS — Part 1** (the 5 Vs framework and one AWS service per V)
- 💻 A laptop with a modern browser
- ☁️ An AWS account (free tier; only for the optional hands-on snippets)
- 🧮 Basic SQL (SELECT, FROM, JOIN, GROUP BY)
- Helpful: the Part 1 S3 → Glue → Athena lab, and familiarity with JSON / CSV / Parquet

:::tip[How to take this course]
Work through the lessons **in order** — the three architectures build on each
other (lake → warehouse → Lake House), and the reference architectures assume
you know all three. This course is concept-heavy with no new hands-on required;
it uses the Part 1 lab as the anchor. Each lesson ends with a short knowledge
check and a **Mark lesson as complete** button so you can track where you left
off.
:::
