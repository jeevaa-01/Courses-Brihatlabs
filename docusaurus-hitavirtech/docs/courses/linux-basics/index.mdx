# Linux Basics with Git Bash Command Line

**Instructor:** HitaVir Tech · **Level:** Beginner to Intermediate · **Estimated total:** ~2.5 hours · **6 modules · 25 lessons**

Welcome to **Linux Basics with Git Bash Command Line** by **HitaVir Tech**!

This hands-on course teaches you Linux command line skills using **Git Bash on Windows**. You do not need a Linux computer. You do not need any prior experience. By the end, you will navigate the terminal like a professional developer.

<LearningObjectives>

- Navigate the file system confidently with `pwd`, `ls`, and `cd`
- Create, copy, move, and delete files and directories entirely from the terminal
- Search files with `grep` and `find`, and chain commands with pipes and redirection
- Manage file permissions with `chmod` and build a real deployment workspace like a junior DevOps engineer

</LearningObjectives>

## What you'll build

Throughout this course you will build and manage a real developer workspace called **hitavir-workspace** entirely from the command line — complete with projects, configs, logs, backup archives, and executable deployment scripts.

## Skills you'll gain

| Skill | Level |
|-------|-------|
| Terminal navigation (pwd, ls, cd) | Beginner |
| File management (mkdir, touch, cp, mv, rm) | Beginner |
| Viewing files (cat, head, tail, less) | Beginner |
| File permissions (ls -l, chmod) | Intermediate |
| Searching (grep, find) | Intermediate |
| Pipes and redirection | Intermediate |
| Environment variables and productivity | Intermediate |

## Prerequisites

- A computer running **Windows 10 or 11** with administrator access
- At least **500 MB** free disk space
- **Zero** prior Linux, terminal, or programming experience required

## Syllabus

| Module | Lessons | Time |
|--------|---------|------|
| **1 · Terminal Foundations** | Prerequisites · Install Git Bash · Linux & shells · pwd, ls, clear · cd | ~29 min |
| **2 · Files & Directories** | mkdir · touch & echo · cp · mv · rm & rmdir | ~25 min |
| **3 · Viewing, Writing & Permissions** | cat, head, tail · redirection · ls -l & chmod | ~21 min |
| **4 · Search, Pipes & Productivity** | grep · find · pipes · environment variables & aliases | ~29 min |
| **5 · Real-World Practice** | DevOps project simulation · troubleshooting | ~17 min |
| **6 · Wrap-Up & Career Prep** | Summary · cheat sheet · interview questions · final quiz · what's next | ~19 min |

:::tip[How to take this course]
Work through the lessons **in order** — every lesson builds on the same
**hitavir-workspace** folder you create in Module 2, so the files you make early
on are the ones you search, pipe, and archive later. Type every command yourself
instead of copy-pasting. Each lesson ends with a short knowledge check and a
**Mark lesson as complete** button so you can track where you left off.
:::
