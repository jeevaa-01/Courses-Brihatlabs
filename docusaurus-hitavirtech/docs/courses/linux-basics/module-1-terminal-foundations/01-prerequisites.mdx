<LearningObjectives>

- Confirm your computer meets the hardware and software requirements
- Understand that no Linux machine or programming background is needed

</LearningObjectives>

Before starting, make sure you have:

### Required

- A computer running **Windows 10 or 11**
- Administrator access (to install software)
- At least **500 MB** free disk space

### No Prior Knowledge Needed

This course assumes **zero experience** with Linux, terminals, or command lines. We start from the very beginning.

### What You Do NOT Need

- You do NOT need Linux installed
- You do NOT need a Mac
- You do NOT need any programming knowledge

:::tip[HitaVir Tech says]
"If you can type on a keyboard, you can learn the command line. It is that simple."
:::

<KeyTakeaways>

- All you need is Windows 10/11, admin rights, and ~500 MB of free disk space
- Git Bash provides the Linux experience — no Linux install or dual-boot required
- The course assumes zero prior terminal or programming experience

</KeyTakeaways>
