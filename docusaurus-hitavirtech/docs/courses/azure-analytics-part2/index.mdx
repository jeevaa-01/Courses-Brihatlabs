# Fundamentals of Analytics on Azure Cloud Platform — Part 2

**Instructor:** HitaVir Tech · **Level:** Beginner–Intermediate · **Estimated total:** ~90 minutes · **4 modules · 12 lessons**

Welcome to **Fundamentals of Analytics on Azure Cloud Platform — Part 2** by **HitaVir Tech**! This is **Part 2 of 2**. In Part 1 you built the mental model — analytics concepts, the 5 Vs, and the Azure service that solves each V. In Part 2 you zoom out and learn **how those services combine** into the production architectures real companies run today.

![Synapse](/img/courses/azure-icons/synapse.svg)

<LearningObjectives>

- Explain what a data lake is, why schema-on-read matters, and how the medallion zones (raw → curated → analytics) are organized
- Describe columnar MPP data warehouses, star schemas, and when to use Synapse Dedicated vs Serverless SQL
- Combine lake and warehouse into the modern Lakehouse architecture, including Microsoft Fabric and OneLake
- Map real-world problems to one of six reference architectures and defend the choice in a design review

</LearningObjectives>

## What you'll master

| Pillar | Topics |
|--------|--------|
| 🪣 **Data Lakes** | What, why, zones, governance on Azure |
| 🏛️ **Data Warehouses** | Columnar MPP, star schemas, Synapse Dedicated |
| 🏡 **Modern Data Architecture** | Lakehouse + Microsoft Fabric |
| ☁️ **Azure Services** | ADLS Gen2, Synapse, Databricks, Purview, ADF, Event Hubs, Power BI |
| 🗺️ **Reference Architectures** | Batch BI, Streaming, ML, Log analytics, 360° customer, Data mesh |
| 🎯 **Common Use Cases** | When to pick which pattern |

## Prerequisites

- Completing **Part 1 — Fundamentals of Analytics on Azure Cloud Platform** (the 5 Vs framework and one Azure service per V; ideally including the ADLS → Synapse Serverless lab)
- Basic SQL (SELECT, FROM, JOIN, GROUP BY)
- A laptop with a modern browser
- An Azure account (free tier) — only needed for the optional hands-on snippets

:::tip[How to take this course]
Work through the lessons **in order** — the three architectures in Module 2 build
on each other, and the reference architectures in Module 3 assume all three. This
course is concept-heavy with no new hands-on required; the Part 1 lab is the
practical anchor. Each lesson ends with a short knowledge check and a **Mark
lesson as complete** button so you can track where you left off.
:::
