**Part 2 tours each architecture**, shows the Azure services that implement it, then demonstrates how real companies blend all three for different use cases.

<KeyTakeaways>

- Three patterns power most modern analytics: the data lake, the data warehouse, and the lakehouse
- Lakes store anything cheaply and forever; warehouses serve fast SQL on curated tables
- The lakehouse combines the strengths of both — it is the "modern data architecture" this course builds toward

</KeyTakeaways>
