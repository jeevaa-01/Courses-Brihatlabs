### What You Should Know

**Required**
- ✅ **Part 1 of this course** (5 Vs + Azure services per V)
- 💻 Laptop with a modern browser
- ☁️ Azure account (free tier; only for the optional hands-on snippets)
- 🧮 Basic SQL (SELECT, FROM, JOIN, GROUP BY)

**Helpful**
- 📝 Completed the Part 1 ADLS → Synapse Serverless lab
- 📚 Familiarity with JSON / CSV / Parquet / Delta

### No Paid Resources Required

Part 2 is concept-heavy. Every diagram is annotated with the services you already met in Part 1. The Part 1 hands-on lab is the practical anchor — this course teaches the architectures that scale it up.

:::warning[If you choose to experiment]
Synapse Dedicated Pools and Databricks can exit the free tier quickly. Use
serverless modes and delete resource groups the same day.
:::

<KeyTakeaways>

- Part 1's 5 Vs framework and Azure service toolkit are the required foundation for Part 2
- Basic SQL is enough — Part 2 is concept-heavy and needs no paid Azure resources
- If you experiment with Dedicated Pools or Databricks, use serverless modes and delete resource groups the same day

</KeyTakeaways>
