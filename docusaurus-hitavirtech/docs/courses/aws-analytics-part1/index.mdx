# Fundamentals of Analytics on AWS — Part 1

**Instructor:** HitaVir Tech · **Level:** Beginner · **Estimated total:** ~2.5 hours · **5 modules · 22 lessons**

Welcome to **Fundamentals of Analytics on AWS — Part 1** by **HitaVirTech**!
This course builds your mental model for analytics in the cloud — one concept
at a time, one AWS service at a time. No prior AWS experience required. This
is **Part 1 of 2**: Part 1 covers concepts, the 5 Vs framework, and the AWS
service mapping; **AWS Analytics Part 2** goes deeper into ETL, Redshift,
streaming, and dashboards.

<LearningObjectives>

- Explain what analytics and machine learning are, and the four maturity levels from descriptive to prescriptive
- Diagnose any data challenge using the 5 Vs framework — Volume, Variety, Velocity, Veracity, Value
- Map each V to the AWS services that solve it (S3, Glue, Kinesis, Lake Formation, QuickSight, and more)
- Build and clean up a real S3 → Glue → Athena pipeline in the AWS console

</LearningObjectives>

## Why the 5 Vs framework matters

Every data challenge you will face maps to one of five questions:

| Question | V |
|----------|---|
| 📦 "How do we store 500 TB?" | Volume |
| 🧩 "We have CSVs, JSON, images — help!" | Variety |
| 🌊 "Dashboards must refresh every second" | Velocity |
| 🛡️ "Half our timestamps are malformed" | Veracity |
| 💎 "Who actually uses this dashboard?" | Value |

The 5 Vs give you a **framework to diagnose**. AWS gives you a **toolbox to solve each V**.

## Prerequisites

- 💻 Laptop — Windows, Mac, or Linux — with a modern web browser
- ☁️ AWS account (free tier is enough; a credit card is needed for sign-up)
- 🧮 Basic SQL (SELECT, FROM, WHERE)
- Helpful but optional: spreadsheet or Python exposure, any other cloud experience

Everything runs in the **AWS web console** — zero software installation. If you
still need a local dev setup for the rest of the program, take
[Windows 11 environment setup](/courses/windows-setup) first.
