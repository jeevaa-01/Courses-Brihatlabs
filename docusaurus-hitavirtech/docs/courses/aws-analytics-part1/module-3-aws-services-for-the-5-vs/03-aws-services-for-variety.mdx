### Athena — One SQL, Many Formats

```sql
SELECT *
FROM   csv_orders
JOIN   json_customers   USING (customer_id)
JOIN   parquet_products USING (product_id);
```

Athena reads **CSV, JSON, Parquet, ORC, Avro** — all via the Glue Catalog. You never leave SQL.

### Unstructured → Structured: The AI Extractor Pipeline

![Rekognition](/img/courses/aws-icons/rekognition.png) ![Textract](/img/courses/aws-icons/textract.png) ![Transcribe](/img/courses/aws-icons/transcribe.png) ![Comprehend](/img/courses/aws-icons/comprehend.png) ![Translate](/img/courses/aws-icons/translate.png)

| Input | Icon | AWS Service | Output |
|-------|:---:|-------------|--------|
| Images | 🖼️ | Rekognition | Labels, faces, moderation |
| PDFs / scans | 📄 | Textract | Extracted text + tables |
| Audio / voice | 🎤 | Transcribe | Transcripts |
| Free text | 💬 | Comprehend | Sentiment, entities, topics |
| Translations | 🌍 | Translate | Languages |

Magic step: **chaos in → structured features out** → then into S3 / Athena / Redshift as normal.

### Real-World Example — E-commerce Review Pipeline

```
  Customer review (raw text)
```

<KeyTakeaways>

- Glue crawlers auto-detect schema and the Data Catalog gives every format one metadata view
- Athena joins CSV, JSON, Parquet, ORC, and Avro in a single SQL statement via the Catalog
- The AI extractors turn chaos into features: Rekognition (images), Textract (PDFs), Transcribe (audio), Comprehend (text)
- Once extracted, unstructured data flows through S3 / Athena / QuickSight like any other table

</KeyTakeaways>
