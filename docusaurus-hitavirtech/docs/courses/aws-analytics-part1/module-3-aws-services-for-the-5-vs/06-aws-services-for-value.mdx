### Redshift ML — SQL-Native Machine Learning

```sql
CREATE MODEL churn_model
FROM   customer_features
TARGET churned
FUNCTION predict_churn
IAM_ROLE DEFAULT
SETTINGS (S3_BUCKET 'my-ml-bucket');

-- then use it
SELECT customer_id, predict_churn(features) AS risk
FROM   customers
WHERE  risk > 0.8;
```

ML without leaving your data warehouse.

<KeyTakeaways>

- QuickSight is AWS's BI layer — SPICE caching for speed, Amazon Q for natural-language questions
- SageMaker covers the full ML lifecycle; Forecast and Personalize package Amazon's own ML as no-code services
- Redshift ML lets you train and run models with plain SQL, without leaving the warehouse
- The value stack climbs from build (S3, Glue, Kinesis) through analysis and ML layers to business outcomes

</KeyTakeaways>
