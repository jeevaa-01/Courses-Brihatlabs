### The Golden Rule — Every Stack Follows One Shape

```
  +-------+   +-------+   +-------+   +-------+   +-------+   +-------+   +-------+
  |       |   |       |   |       |   |       |   |       |   |       |   |       |
  | INGST | ->| STORE | ->| CATLG | ->| PROCS | ->| QUERY | ->| VIEW  | ->|  ACT  |
  |       |   |       |   |       |   |       |   |       |   |       |   |       |
  +-------+   +-------+   +-------+   +-------+   +-------+   +-------+   +-------+
```

The **5 Vs** tell you where the bottleneck is. The **AWS services** tell you what solves it.

<KeyTakeaways>

- Every analytics stack follows one shape: ingest → store → catalog → process → query → view → act
- The 5 Vs diagnose where your bottleneck is; AWS services are the toolbox that fixes it
- The next five lessons cover one dedicated service lineup per V

</KeyTakeaways>
