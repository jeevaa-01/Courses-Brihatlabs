Every box maps to a V. Every arrow is a managed Azure service.

<KeyTakeaways>

- The ingest layer handles Velocity (Event Hubs, Functions) and Variety (Data Factory, AI extractors) side by side
- ADLS Gen2 with its raw / curated / analytics zones is the Volume backbone, cataloged by Purview
- Veracity lives inside the processing layer — quality rules run where data is transformed
- Everything converges on the Value layer: Power BI, Copilot, Azure OpenAI, Personalizer → decisions
- Every box in the architecture is a managed service — no servers to run

</KeyTakeaways>
