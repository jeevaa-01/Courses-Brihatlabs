```
  RULES                                          CHECK RESULT
  -----                                          -------------
```

### Activity Log + Policy — The Audit Twins

![Activity Log](/img/courses/azure-icons/activity-log.svg) ![Policy](/img/courses/azure-icons/policy.svg)

- 📜 **Activity Log** — "Who did WHAT and WHEN?" Every ARM API call logged.
- ⚙️ **Azure Policy** — "What rules must resources follow?" Enforce compliance as code.

Essential for regulated industries (finance, healthcare, gov).

### The Data Quality Lifecycle

```
  PROFILE  --->  DEFINE RULES  --->  ENFORCE  --->  ALERT  --->  FIX  --->  MONITOR
  (know)         (expected)           (every run)    (fail fast)  (fix)     (trends)
     ^                                                                         |
     |                                                                         |
     +---------------------------- loop ---------------------------------------+
```

### Real-World Example — Sales Lake Quality Gate

```
  Raw sales CSV from 50 stores
        |
        v
  ADF Mapping Data Flow reads it
        |
        v
  Purview Data Quality rules:
     PASS - order_id unique
     PASS - amount in [0, 1M]
     FAIL - store_id in valid list   (12 rows failed)
        |
        v
     +--+--+
     v     v
  Quarantine   Curated
  container +  zone
  Teams alert  (Parquet)
```

:::tip[HitaVir Tech says]
"Every pipeline must have quality rules — not 'someday', from day one. 10x
cheaper to catch bad data at ingest than to explain a wrong dashboard to the CEO."
:::

<KeyTakeaways>

- ADF Mapping Data Flows give analysts 90+ no-code transforms on a managed Spark engine
- Microsoft Purview combines catalog, column-level lineage, and rule-based data quality — the governance nervous system
- Defender for Cloud finds PII hiding in storage; Activity Log and Azure Policy are the audit twins for regulated industries
- The quality lifecycle loops: profile → define rules → enforce → alert → fix → monitor
- Failing rows go to quarantine with an alert — never silently into the curated zone

</KeyTakeaways>
