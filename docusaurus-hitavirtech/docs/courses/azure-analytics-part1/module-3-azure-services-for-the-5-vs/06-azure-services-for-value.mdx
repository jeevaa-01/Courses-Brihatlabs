### Synapse ML — SQL-Native Machine Learning

```sql
CREATE EXTERNAL MODEL churn_model
FROM   (SELECT * FROM customer_features)
WITH  (MODEL_TYPE = 'Binary Classification',
       LABEL_COLUMN = 'churned');

-- then use it
SELECT customer_id, PREDICT(MODEL = churn_model, DATA = features) AS risk
FROM   customers
WHERE  risk > 0.8;
```

ML without leaving your Synapse warehouse.

### The Value Stack

```
  +==============================================================+
  |                                                              |
  |   BUSINESS  VALUE      revenue - savings - growth            |
  |        ^                                                     |
  |        |                                                     |
  |   APPLICATION LAYER    Personalizer, Metrics Advisor, AD     |
  |        ^                                                     |
  |        |                                                     |
  |   ML LAYER             Azure ML, Synapse ML, OpenAI          |
  |        ^                                                     |
  |        |                                                     |
  |   ANALYSIS LAYER       Synapse + Power BI + Fabric           |
  |        ^                                                     |
  |        |                                                     |
  |   BUILD LAYER          ADLS + ADF + Event Hubs + Purview     |
  |                                                              |
  +==============================================================+
```

:::tip[HitaVir Tech says]
"The best data platform is worthless if nobody uses the outputs. Start from
Value and work backwards — who sees which insight, and what decision changes?
Design everything else to serve that."
:::

<KeyTakeaways>

- Power BI (VertiPaq engine, Copilot, Embedded) is the delivery end of the Azure value chain
- Azure ML covers the full lifecycle — Studio, AutoML, pipelines, MLOps registry and endpoints
- Azure OpenAI serves GPT-class models inside your compliance boundary; RAG with AI Search grounds them in your lake
- Applied AI services (Personalizer, Anomaly Detector, Metrics Advisor) deliver ML outcomes without building models
- The value stack: build layer → analysis layer → ML layer → application layer → business value

</KeyTakeaways>
