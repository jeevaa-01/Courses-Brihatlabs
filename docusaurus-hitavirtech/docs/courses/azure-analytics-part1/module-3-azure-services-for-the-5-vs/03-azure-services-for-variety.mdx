### Synapse Serverless SQL — One SQL, Many Formats

```sql
SELECT  c.customer_id, SUM(o.amount) AS total_spent
FROM    OPENROWSET(
          BULK 'https://hitavirtech.dfs.core.windows.net/lake/orders/*.parquet',
          FORMAT = 'PARQUET'
        ) AS o
JOIN    OPENROWSET(
          BULK 'https://hitavirtech.dfs.core.windows.net/lake/customers/*.json',
          FORMAT = 'CSV', FIELDTERMINATOR='0x0b'
        ) AS c  ON c.customer_id = o.customer_id
GROUP BY c.customer_id;
```

Serverless SQL reads **CSV, JSON, Parquet, Delta** directly from ADLS. You never leave T-SQL.

![AI Vision](/img/courses/azure-icons/ai-vision.svg) ![Doc Intelligence](/img/courses/azure-icons/doc-intelligence.svg) ![AI Speech](/img/courses/azure-icons/ai-speech.svg) ![AI Language](/img/courses/azure-icons/ai-language.svg) ![Translator](/img/courses/azure-icons/translator.svg)

Magic step: **chaos in → structured features out** → then into ADLS / Synapse / Databricks as normal.

<KeyTakeaways>

- ADLS Gen2 holds every format; Data Factory orchestrates movement with 100+ connectors
- Synapse Serverless `OPENROWSET` queries CSV, JSON, Parquet, and Delta from the lake without leaving T-SQL
- The AI extractor services (Vision, Doc Intelligence, Speech, Language, Translator) turn unstructured inputs into structured features
- Decision tree by format: tabular/JSON → ADLS + Synapse (or Cosmos), images → AI Vision, PDFs → Doc Intelligence, audio → AI Speech, free text → AI Language

</KeyTakeaways>
