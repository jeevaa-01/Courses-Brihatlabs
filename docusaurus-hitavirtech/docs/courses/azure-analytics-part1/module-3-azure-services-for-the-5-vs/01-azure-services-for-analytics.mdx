### The Golden Rule — Every Stack Follows One Shape

```
  +-------+   +-------+   +-------+   +-------+   +-------+   +-------+   +-------+
  |       |   |       |   |       |   |       |   |       |   |       |   |       |
  | INGST | ->| STORE | ->| CATLG | ->| PROCS | ->| QUERY | ->| VIEW  | ->|  ACT  |
  |       |   |       |   |       |   |       |   |       |   |       |   |       |
  +-------+   +-------+   +-------+   +-------+   +-------+   +-------+   +-------+
```

The **5 Vs** tell you where the bottleneck is. The **Azure services** tell you what solves it.

<KeyTakeaways>

- Every analytics stack follows one shape: ingest → store → catalog → process → query → view → act
- The 5 Vs diagnose the bottleneck; Azure services are the toolbox that fixes it
- The headline cast — ADLS Gen2, Synapse, Databricks, Data Factory, Event Hubs, Stream Analytics, Functions, Power BI, Azure ML, Azure OpenAI — will reappear throughout this module

</KeyTakeaways>
