<KeyTakeaways>

- Analytics is the goal: turning data into decisions
- Machine learning powers the advanced levels of analytics
- The 5 Vs of Big Data describe the challenges that make analytics hard at scale
- Each anchor idea maps to a family of Azure services you will meet in Module 3
