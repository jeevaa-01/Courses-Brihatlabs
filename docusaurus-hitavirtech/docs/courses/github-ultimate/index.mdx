# GitHub Ultimate: Master Git and GitHub — Beginner to Expert

**Instructor:** HitaVir Tech · **Level:** Beginner to Expert · **Estimated total:** ~4 hours · **7 modules · 32 lessons**

Welcome to **GitHub Ultimate** by **HitaVirTech**! This is a complete, hands-on
course that takes you from zero Git knowledge to confidently managing
real-world projects with Git and GitHub. Throughout the course you build and
manage a real project repository called **hitavir-portfolio** — creating it
from scratch, collaborating with simulated teammates on branches, raising pull
requests, resolving conflicts, and wiring up automated CI with GitHub Actions.

<LearningObjectives>

- Track any project with the core Git workflow: init, add, commit, status, and log
- Branch, merge, and resolve conflicts confidently — then undo mistakes safely with restore, reset, and revert
- Collaborate on GitHub with remotes, pull requests, code reviews, and forks
- Apply expert tools — rebasing, cherry-pick, stash, tags, hooks, and GitHub Actions CI/CD — in a real team simulation

</LearningObjectives>

## Prerequisites

- A computer (Windows, Mac, or Linux) with an internet connection
- A text editor (VS Code recommended — [download here](https://code.visualstudio.com/))
- A free GitHub account — [sign up here](https://github.com/join)
- **Zero Git experience needed** — we start from the very basics

## Syllabus

| Module | Lessons | Time |
|--------|---------|------|
| **1 · Getting Started with Git** | Prerequisites · Install Git · Configure Git · What is Git? What is GitHub? | ~21 min |
| **2 · Git Fundamentals** | First repository · Add/commit/status workflow · Staging area · .gitignore | ~28 min |
| **3 · Branching, Merging & Undoing** | Branching · Merging · Merge conflicts · Reset, revert, checkout | ~38 min |
| **4 · Remotes, Pull Requests & Code Reviews** | Remote repositories · Pull requests · Code reviews | ~25 min |
| **5 · Advanced Git Techniques** | Rebasing vs merging · Cherry-pick · Stashing · Tags and releases | ~23 min |
| **6 · Automation, Internals & Open Source** | GitHub Actions CI/CD · Forking · Git internals · Interactive rebase · Git hooks | ~46 min |
| **7 · Real-World Workflows & Wrap-Up** | Collaboration workflows · Team simulation · Summary · Cheat sheet · Interview questions · Final quiz | ~47 min |

:::tip[How to take this course]
Work through the lessons **in order** — the `hitavir-portfolio` project grows
lesson by lesson, so later commands build on earlier ones. Type every command
yourself (do not copy-paste blindly), compare your output with the expected
output shown, and re-read the step if you get stuck — the answer is always
there. Each lesson ends with a short knowledge check and a **Mark lesson as
complete** button so you can track where you left off.
:::
