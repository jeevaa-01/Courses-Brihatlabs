# Data Engineering Environment Setup on Windows 11

**Instructor:** HitaVir Tech · **Level:** Beginner · **Estimated total:** ~45 minutes · **4 modules · 11 lessons**

Welcome to **HitaVirTech**! This course walks you through setting up a complete
Data Engineering development environment on **Windows 11** from scratch. Every
other course in the program builds on the tools you install here.

<LearningObjectives>

- Install and verify the nine core tools of a professional data engineering workstation
- Configure Git with SSH keys and connect it to a new GitHub account
- Stand up a local PySpark environment (Python 3.11 + Java 11 + Spark 3.5)
- Run containerized services with Docker Desktop and WSL2

</LearningObjectives>

## What you'll install

| Tool | Purpose |
|------|---------|
| Windows Terminal | Modern terminal experience |
| Git & Git Bash | Version control & Unix shell on Windows |
| Python 3.11 | Core scripting & PySpark |
| Java 11 (JDK) | Required for PySpark / Spark |
| Apache Spark | Local Spark for PySpark development |
| VS Code | Primary IDE |
| GitHub Account | Cloud version control & collaboration |
| Databricks CLI | Connect to Databricks workspace |
| Docker Desktop | Containerized environments |

## Prerequisites

- Windows 11 (64-bit) with admin rights
- At least **16 GB RAM** (8 GB minimum)
- At least **50 GB** free disk space
- Stable internet connection
- A valid email address (for the GitHub account)

## Syllabus

| Module | Lessons | Time |
|--------|---------|------|
| **1 · Terminal & Version Control** | Windows Terminal · Git & Git Bash | ~8 min |
| **2 · Python, Java & Spark** | Python 3.11 · Java 11 JDK · Apache Spark | ~15 min |
| **3 · IDE, GitHub & Cloud Tools** | VS Code · GitHub account · Databricks CLI · Docker Desktop | ~19 min |
| **4 · Verify & Wrap Up** | Final verification checklist · Final quiz · Next steps | ~5 min |

:::tip[How to take this course]
Work through the lessons **in order** — later installs depend on earlier ones
(e.g., Spark needs Java, GitHub needs the SSH key from the Git lesson). Each
lesson ends with a short knowledge check and a **Mark lesson as complete**
button so you can track where you left off.
:::
