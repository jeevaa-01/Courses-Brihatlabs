<LearningObjectives>

- Install the Databricks CLI via winget or pip
- Configure a named profile with a personal access token
- Verify connectivity by listing workspace clusters

</LearningObjectives>
### Step 1 - Install

```powershell
winget install Databricks.DatabricksCLI
```

Or via pip:
```bash
pip install databricks-cli
```

### Step 2 - Configure

```bash
databricks configure --token --profile hitavir-dev
# Databricks Host: https://adb-XXXXXXXXXX.azuredatabricks.net
# Token: dapiXXXXXXXXXXXXXXXX
```

Generate token: Databricks > **User Settings > Developer > Access Tokens > Generate New Token**

### Verify

```bash
databricks --version
# Databricks CLI v0.x.x

databricks clusters list --profile hitavir-dev
```

<KeyTakeaways>

- Profiles (`--profile hitavir-dev`) let you target multiple workspaces from one machine
- Tokens are generated in Databricks under **User Settings → Developer → Access Tokens**
- Treat access tokens like passwords — never commit them to a repository

</KeyTakeaways>
