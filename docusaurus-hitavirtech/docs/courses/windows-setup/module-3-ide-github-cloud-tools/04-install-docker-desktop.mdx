<LearningObjectives>

- Enable WSL2 with an Ubuntu 22.04 distribution
- Install Docker Desktop on the WSL2 backend
- Run and verify a PostgreSQL 15 container

</LearningObjectives>
### Step 1 - Enable WSL2

```powershell
# PowerShell as Administrator - then restart PC
wsl --install
```

After restart:
```powershell
wsl --set-default-version 2
wsl --install -d Ubuntu-22.04
```

### Step 2 - Install Docker Desktop

Download from [https://www.docker.com/products/docker-desktop/](https://www.docker.com/products/docker-desktop/)

Install settings:
- Use **WSL 2** instead of Hyper-V
- Add shortcut to desktop

### Verify Docker

```bash
docker --version
# Docker version 26.x.x

docker run hello-world
# Hello from Docker!
```

### Test with PostgreSQL

```bash
docker run -d \
  --name pg-dev \
  -e POSTGRES_PASSWORD=hitavir123 \
  -e POSTGRES_DB=dataengineering \
  -p 5432:5432 \
  postgres:15

docker ps
```

<KeyTakeaways>

- Docker Desktop on Windows runs on the **WSL2** backend — enable it first, then restart
- `docker run hello-world` is the canonical install check
- One `docker run` command gives you a disposable PostgreSQL for local pipelines

</KeyTakeaways>
