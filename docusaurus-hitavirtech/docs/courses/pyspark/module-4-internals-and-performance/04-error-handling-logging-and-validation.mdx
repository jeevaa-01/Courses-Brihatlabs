# Error Handling, Logging, and Validation

*⏱ Estimated time: 75 minutes*

:::note[🎯 Learning objectives]

By the end of this section, you will be able to:

- Configure structured logging for a pipeline run.
- Validate input paths, required columns, and non-empty inputs.
- Emit rejected-record counts and fail loudly when assumptions are violated.

:::

### Python logging

```python
import logging
from pathlib import Path

log_path = Path("logs/pipeline.log")
log_path.parent.mkdir(parents=True, exist_ok=True)

logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s | %(levelname)s | %(message)s",
    handlers=[
        logging.FileHandler(
            log_path,
            encoding="utf-8"
        ),
        logging.StreamHandler()
    ]
)

logger = logging.getLogger(__name__)
```

### Validate input path

This pattern applies to local file systems. On Databricks, check volume paths with `dbutils.fs.ls` or `os.path.exists` on `/Volumes/...` paths.

```python
from pathlib import Path

input_path = Path("data/raw/sales.csv")

if not input_path.exists():
    raise FileNotFoundError(
        f"Input not found: {input_path}"
    )
```

### Validate required columns

```python
def validate_required_columns(
    df,
    required_columns: set[str]
) -> None:
    missing_columns = required_columns - set(df.columns)

    if missing_columns:
        raise ValueError(
            f"Missing columns: {sorted(missing_columns)}"
        )
```

### Validate non-empty input

```python
if df.limit(1).count() == 0:
    raise ValueError("Input DataFrame is empty")
```

### Count rejected records

```python
rejected_count = rejected_df.count()

logger.warning(
    "Rejected rows: %s",
    rejected_count
)
```

### Handle exceptions

```python
try:
    run_pipeline()
except Exception:
    logger.exception("Pipeline failed")
    raise
```

### Data quality checks

Check:

- Required columns.
- Null transaction IDs.
- Duplicate transaction IDs.
- Invalid dates.
- Negative quantity.
- Negative price.
- Unexpected region.
- Empty product.
- Row count thresholds.
- Join match rate.

Example:

```python
duplicate_count = (
    df.groupBy("transaction_id")
    .count()
    .filter(F.col("count") > 1)
    .count()
)

if duplicate_count > 0:
    logger.warning(
        "Duplicate transaction IDs: %s",
        duplicate_count
    )
```

- Log run ID, counts, rejections, outputs, duration, and status on every run.
