# GitHub Repository Example

*⏱ Estimated time: 20 minutes*

:::note[🎯 Learning objectives]

By the end of this section, you will be able to:

- Organize the project as a shareable Git repository.
- Exclude generated outputs and secrets with a proper `.gitignore`.
- Identify where CI would run your PySpark tests.

:::

Recommended repository:

```text
hitavir-pyspark-data-engineering/
│
├── data/
│   ├── raw/
│   ├── processed/
│   └── rejected/
│
├── docs/
│   ├── architecture.md
│   └── data_contract.md
│
├── logs/
│
├── notebooks/
│   └── exploration.ipynb
│
├── src/
│   ├── __init__.py
│   ├── config.py
│   ├── schemas.py
│   ├── spark_session.py
│   ├── extract.py
│   ├── transform.py
│   ├── load.py
│   └── pipeline.py
│
├── tests/
│   ├── conftest.py
│   └── test_transform.py
│
├── .env.example
├── .gitignore
├── README.md
└── requirements.txt
```

Example `.gitignore`:

```gitignore
.venv/
__pycache__/
*.pyc
.pytest_cache/
.vscode/
.env
logs/*.log
data/processed/
data/rejected/
```

Git commands:

```powershell
git init
git add .
git commit -m "Create HitaVir Tech PySpark pipeline"
```

Branch:

```powershell
git checkout -b feature/add-customer-enrichment
```
