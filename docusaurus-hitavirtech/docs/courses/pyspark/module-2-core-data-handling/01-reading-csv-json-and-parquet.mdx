### Read CSV with schema

```python
from pyspark.sql.types import (
    DoubleType,
    IntegerType,
    StringType,
    StructField,
    StructType,
)

schema = StructType(
    [
        StructField("transaction_id", StringType(), True),
        StructField("transaction_date", StringType(), True),
        StructField("region", StringType(), True),
        StructField("product", StringType(), True),
        StructField("quantity", IntegerType(), True),
        StructField("unit_price", DoubleType(), True),
    ]
)

sales_df = (
    spark.read
    .option("header", True)
    .schema(schema)
    .csv(f"{BASE_PATH}/raw/sales.csv")
)

sales_df.show()
sales_df.printSchema()
```

### CSV options

```python
csv_df = (
    spark.read
    .option("header", True)
    .option("delimiter", ",")
    .option("quote", '"')
    .option("escape", '"')
    .option("mode", "PERMISSIVE")
    .schema(schema)
    .csv(f"{BASE_PATH}/raw/sales.csv")
)
```

Modes:

- `PERMISSIVE`
- `DROPMALFORMED`
- `FAILFAST`

### Read JSON

Create `events.json` in `{BASE_PATH}/raw` (on Databricks, use `dbutils.fs.put` as shown in [Create a CSV file](/courses/pyspark/module-2-core-data-handling/reading-csv-json-and-parquet#create-a-csv-file)):

```json
{"event_id":"E001","event_type":"view","user_id":"U001"}
{"event_id":"E002","event_type":"purchase","user_id":"U002"}
{"event_id":"E003","event_type":"view","user_id":"U001"}
```

Read:

```python
events_df = spark.read.json(f"{BASE_PATH}/raw/events.json")

events_df.show()
events_df.printSchema()
```

### Multiline JSON

For a JSON array:

```json
[
  {"event_id":"E001","event_type":"view"},
  {"event_id":"E002","event_type":"purchase"}
]
```

Use:

```python
events_df = (
    spark.read
    .option("multiline", True)
    .json(f"{BASE_PATH}/raw/events_array.json")
)
```

### Read Parquet

```python
parquet_df = spark.read.parquet(
    f"{BASE_PATH}/processed/clean_sales"
)
```

### Why Parquet is preferred

Parquet is:

- Columnar.
- Compressed.
- Schema-aware.
- Efficient for analytics.
- Compatible with predicate pushdown.
- Widely supported.

### Read multiple files

```python
sales_df = spark.read.schema(schema).csv(
    f"{BASE_PATH}/raw/sales/*.csv"
)
```

:::info[📌 Key takeaways]

- Use CSV and JSON for interchange, Parquet (or Delta) for analytical storage.
- Always pair reads with an explicit schema in pipelines.
- Reader modes control what happens to malformed records.

:::

:::tip[💡 HitaVir Tech Tip]

Use CSV for interchange and Parquet for scalable analytical storage.

:::

:::info[🚀 Pro Tip]

For large lakes, prefer many reasonably sized Parquet files instead of millions of tiny files.

:::
