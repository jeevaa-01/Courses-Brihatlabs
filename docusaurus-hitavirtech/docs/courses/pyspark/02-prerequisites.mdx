# Prerequisites

*⏱ Estimated time: 5 minutes*

You need:

- A modern web browser and an email address (for Databricks Free Edition).
- Internet access.
- Basic Python knowledge.
- Basic SQL knowledge is helpful but not mandatory.
- Familiarity with CSV files.

Only for the optional local Windows setup:

- Windows 10 or Windows 11.
- Administrator or software installation permission.
- At least 8 GB RAM. 16 GB is recommended.
- At least 5 GB free disk space.

Recommended understanding before starting:

- Python variables and functions.
- Lists and dictionaries.
- File paths.
- Virtual environments.
- Basic Data Engineering concepts.

:::tip[💡 HitaVir Tech Tip]

PySpark becomes easier when you understand Python and SQL fundamentals first.

:::

:::info[🚀 Pro Tip]

Spark is designed for distributed processing. Learn the concepts on one machine, but always think in terms of partitions, workers, shuffles, and cluster execution.

:::
