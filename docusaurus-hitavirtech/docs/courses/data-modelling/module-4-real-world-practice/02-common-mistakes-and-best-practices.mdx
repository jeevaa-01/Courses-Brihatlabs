### Naming Conventions

![Naming Conventions](/img/courses/diagrams/naming-conventions.svg)

:::tip[HitaVir Tech Best Practice]
"Document your grain statement for every fact table. Example: 'One row per product per order per day.' If you cannot state the grain in one sentence, your model needs work."
:::

<KeyTakeaways>

- Most modelling failures trace back to an undeclared or fuzzy fact table grain
- Consistent prefixes (fact_, dim_) and snake_case names keep warehouses navigable
- Write the grain statement in one sentence and store it with the table documentation
- If you cannot state the grain in one sentence, the model needs rework

</KeyTakeaways>
