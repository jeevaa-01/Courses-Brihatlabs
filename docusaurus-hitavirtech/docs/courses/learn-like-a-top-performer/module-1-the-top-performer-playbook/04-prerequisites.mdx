<LearningObjectives>

- Verify you have the minimal toolset: a terminal, Git, a text editor, and a GitHub account
- Commit to the six non-negotiable mindset prerequisites

</LearningObjectives>

### What You Need

| Requirement | Details |
|-------------|---------|
| Computer | Any OS (Windows, Mac, or Linux) |
| Terminal | Git Bash (Windows), Terminal (Mac/Linux) |
| Git | Installed and configured |
| Text Editor | VS Code recommended |
| GitHub Account | Free account at github.com |

### Mindset Prerequisites (Non-Negotiable)

```
Commit to these before starting:
  [ ] I will type every command myself
  [ ] I will read every error message completely
  [ ] I will attempt rebuilds without the guide
  [ ] I will keep a daily learning journal
  [ ] I will ask for help after 20 minutes of being stuck
  [ ] I understand that struggling IS the learning process
```

:::warning[No shortcuts]
If you are not ready to commit to these, stop here. Come back when you are. There are no shortcuts on this path.
:::

<KeyTakeaways>

- Hardware and OS barely matter — any computer with a terminal, Git, VS Code, and a GitHub account is enough
- The real prerequisites are behavioral: type everything yourself, read every error fully, journal daily
- Struggling IS the learning process — commit to that before you start

</KeyTakeaways>
